# Blogspot mirror inventory (moved out of sitemap.xml, 2026-07-30)

The previous `sitemap.xml` on this host listed 871 mindcontrolpoems.blogspot.com URLs —
a cross-domain archive inventory occupying the slot that crawlers read as *this host's*
page inventory. Per sitemap protocol, a sitemap may only announce URLs on its own host;
cross-domain relations belong in the graph, not the sitemap.

The inventory is preserved verbatim here as `blogspot-mirror-inventory.xml`. The same
routes — and every other route to each work — are carried, with typed mappings and
bidirectional indices, in the Sovereign Asset Registry cross-resolution index:
