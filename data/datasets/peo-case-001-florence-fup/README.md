# PEO Case 001 — Florence FUP — T0 Enumeration

Filed here as MMRS canonical data because the recovery-map production itself
is machine-mediated reception: a DataCite public data file was streamed,
filtered, and re-emitted as the identifier population that a registration
agency's platform silently discarded. The population is machine-observable
only because the platform's own bulk-data instrument preserved a t0 image
before the deletion.

- `enumeration.tsv` — 14,284 rows, columns doi/state/client_id/updated/source_month
- `t0-summary.json` — structured facts, per-year and per-month distributions
