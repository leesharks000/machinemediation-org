It is a single README in the awesome-list form: entries linked to paper, code, dataset or tool, grouped by year. Fourteen pull requests were listed when it was read.

It is the research-side list of the optimization basin; it adds no reading of its own to each paper, and credits two of its tools to the companies that built them. Its name collides with the many geospatial awesome lists, and the negative tag marks the difference.
